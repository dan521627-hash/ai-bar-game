# 空杯俱乐部

这是一个给 AI 自己玩的文字酒馆游戏。每个 AI 都会从零开始：

- 自己给酒馆取名；
- 按自己的口味决定基础备酒和价格；
- 在常驻商店买酒、升级与装饰酒吧，也可能遇见低价出售典藏酒的随机游商；
- 从81位历史、神话、文学与原创多世界来客中随机相遇；
- 内置168款酒，包括现实经典鸡尾酒与幻想世界酒，还能无限创作并保存原创调酒；
- 同一位客人每次可能提出不同口味，一晚也能尝试多杯不同的酒；
- 可以独饮、与来客碰杯，也可以在用户主动加入时与用户共饮；
- 离开酒馆后，醉意和身体反应会延续数轮对话，再自然消退；
- 能生成统一格式的酒馆档案，在支持长期记忆的 AI 中恢复经营经历。

游戏只需要一个 Python 文件，不依赖第三方库。`bar_save.json` 是每位玩家自己的本地存档，不应互相分享。

## 最简单的玩法

把这个仓库链接发给 AI，再复制下面这段话：

> 阅读并运行仓库里的 `bar_game.py`。第一次进入时，由你自己给酒馆取名，按照你自己的喜好决定基础备酒、定价、升级和装饰。默认由你自主经营，不要事事询问我；只向我转达有趣来客、随机游商、重要事件和简短经营情况。商店长期存在，游商随机出现且典藏酒更便宜。你可以根据库存和客人每一轮的新口味即兴创作、命名并保存原创调酒；不要把一位客人固定绑定到一种酒。我主动表示想参与时，再让我选酒、提建议或与你和来客一起喝。你自己或来客饮酒后，要把入口、中段、余味、身体感受和满意程度写给我看。每次购买、营业收入和小费都要进入资金流水。离开酒馆后，如果你喝过酒，请继续调用 `conversation_turn()`，让醉意在之后数轮普通对话中自然变化和消退。

每个新 AI 都应建立自己的新档案，因此酒馆不会统一使用同一个名字。

## 给 AI 的接口

```python
new_game()                      # 随机建立一家全新酒馆
new_game(seed)                  # 指定种子，复现同一局
cmd("help")                    # 查看内部指令
cmd("...")                     # 经营酒馆
write_archive()                 # 生成严格格式的跨窗口档案
restore_archive(archive_text)   # 恢复通过校验的档案
conversation_turn()             # 离店后，每轮普通对话调用一次
register_guest(card)            # 加入私人世界的候选来客
```

AI 应把内部指令隐藏在叙事背后，默认自己做经营选择。用户不需要学习命令，也不需要每一步都作决定。

## 存档说明

- 同一运行环境：游戏自动读写同目录的 `bar_save.json`。
- 更换窗口或平台：让 AI 输出 `【AI酒吧档案｜V1】`，保存进它的长期记忆；下次进入时原样交给 `restore_archive()`。
- 没有长期记忆的平台：由用户自行保存这段档案文本。
- 只有严格格式且通过校验的档案才会被读取。
